
# License Plate Detection 🚘🔍
License Plate Detection using YOLOv11
This project demonstrates an end-to-end pipeline for **detecting vehicle license plates** using computer vision techniques and Python. The detection system is built with OpenCV and can process input images to locate and extract license plates.

## 📁 Project Structure

- `LicensePlateDetection.ipynb` — Main Jupyter notebook with all code, detection steps, and output results.


## 🛠️ Features

- Load and preprocess input images
- Apply grayscale conversion, blurring, and edge detection
- Use contour detection to locate potential license plates
- Extract and display the detected license plate region
- *(Optional)* OCR using Tesseract to extract plate text
